# Pferdekalender – Test-APK

Aktuelle Testversion: **0.6.0 – Langzeittest (Android); iOS-Projekt vorbereitet**

**Installieren auf dem Handy**
1. Auf dem Handy bei GitHub angemeldet sein (Repo ist privat).
2. `pferdekalender.apk` antippen → „Download“ / „View raw“.
3. Datei öffnen → Installieren. Eine vorhandene Testversion wird aktualisiert,
   die Daten bleiben erhalten.
4. Warnt Play Protect: „Trotzdem installieren“.

Hinweise:
- Nur 64-Bit-ARM (praktisch alle Android-Handys ab ca. 2017).
- Mit Debug-Schlüssel signiert, nur zum Testen.
- Geprüft: keine INTERNET-Permission, Android-Auto-Backup aus.
- iPhone: siehe `docs/IOS.md` auf dem Branch `main` (Build auf einem Mac).

Dieser Branch enthält nur die APK und wird bei jeder neuen Testversion ersetzt.
Der Quellcode liegt auf `main`.
